How to Backup Panel Files

Written by Kocheng Team

Published on September 20, 2025 · 6 min read

This guide describes how to back up your server files through the Kocheng Hosting panel. Backups help protect your data if the panel restarts or your server experiences unexpected problems.

Note: Before starting a backup, confirm that an active server containing files is available. The backup process cannot start without server files.

Step 1 — Open the Backup Page

Go to control.kocheng.biz.id/panel/backup, where you will find a table of your backups and a Start Backup button.

Step 2 — Start a Backup

Click Start Backup, then wait for the process to finish. The time required may vary based on the size of your server files.

Step 3 — Download or Upload to Cloud

Once the backup is complete, two options will appear:

  • Download: Save the backup file directly on your device.
  • Upload to Cloud: Transfer the backup file to Kocheng Hosting’s cloud storage. This keeps your data protected if the panel restarts, provided you sign in with the same account.

Step 4 — Restore from Cloud

If you select Upload to Cloud, an additional Restore option becomes available. Use it to download the backup file from cloud storage and restore it to your server whenever necessary.

Step 5 — Enable Auto Backup

You can also turn on the Auto Backup feature. After it is enabled, your server files will be backed up automatically once a week, so you won’t need to perform backups manually.

Troubleshooting & Tips

  • Backup failure: Check that your server has sufficient disk space, then try again.
  • Download issue: Change your network connection (Wi-Fi ↔ mobile data) and retry.
  • Cloud upload failure: Make sure you are signed in to the correct account and have not exceeded your cloud storage quota.
  • Restore error: Verify that the backup is available in your cloud storage. If the problem continues, contact support.
  • Automatic backup not running: Confirm that automatic backup is enabled, then wait for the scheduled weekly backup day.

With manual and automatic backups, cloud uploads, and restore capabilities, your server files are always protected and can be recovered whenever needed.
