How to Complete the Ad Verification to Create a Free Server

Written by Kocheng Team

Published on September 14, 2025 · 3 min read

Kocheng Hosting uses a brief ad-verification process to help sustain its free server tier. This article provides step-by-step instructions for safely completing website-based ad verification so your server can be provisioned correctly.

Quick summary: Log in → open the Dashboard → select Server → choose Create Server → complete the ad flow → return to the server creation page → enter the required information → create the server.

Prerequisites

  • Sign in to your Kocheng Hosting account and open the dashboard.
  • For optimal compatibility, use a current mobile browser or an up-to-date Android/iOS device.

Step-by-step Instructions

  1. Start the server creation process.

    On your dashboard, tap the three-line menu icon in the top-left corner, choose Server, and then tap Create Server using the website method.

  2. Review the ad page.

    You will be redirected to an advertisement and verification page. This page is part of the ad-supported process. Follow the steps below to confirm that you viewed the ad.

  3. Select the “I’m human” button.

    On the ad page, find and select the “I’m human” button or another verification button with similar wording. A brief countdown, typically about 3 seconds, will then appear.

  4. Wait for the countdown to end, then follow the on-screen instruction.

    Once the countdown is complete, select the Get Link or Get URL button that appears to proceed.

  5. Go back to the server creation page.

    Once you tap Get Link, you will be taken to the free server creation form. If the ad opens in a new tab or full-screen mode, use your browser's back button to return to the original form.

  6. Complete the server setup form.

    Enter the required information, including the Server Name, select the Node, and choose the appropriate Egg based on your bot or server type.

  7. Submit the flow to complete it.

    Select the action button, such as Watch Ad & Create Server. If ad verification redirects you again, follow the instructions to repeat the back-button step. This confirms the view and enables the creation process to continue.

  8. Confirm provisioning.

    After verification succeeds, the site will activate the creation option and provision your server. Once provisioning is complete, you will see the server information and panel credentials.

Important Cautions

Warning: Advertisement pages may include various external advertisements and promotional materials. Do not provide personal information on third-party websites, and do not download files from unknown sources. If an advertisement requests unnecessary permissions or tries to install software, close the page immediately and return to the creation form.

Troubleshooting Tips

  • Ad button missing: Wait several seconds, then refresh the ad page. If the issue continues, switch networks (mobile data ↔ Wi-Fi).
  • Redirect loop: Close any extra tabs, and press the browser back button once the ad timer finishes.
  • Verification cannot be completed: Try a different device, or contact support and include a screenshot along with the exact step where the process failed.
  • Privacy concern: Third parties provide the ads, so do not enter sensitive personal information on ad pages. See our Ads Disclosure for more information.
